### 1.3 권장 기능 (우선순위)

**P1 — 사용자 체감 가장 큰 것**
1. **인앱 자동 업데이트** — `ContactUrl`(GitHub)로 Releases를 확인하고, 최신 버전이 있으면 알림 + 다운로드 (BibleSlide 방식). 현재 "업데이트" 버튼은 GitHub 페이지를 열기만 함.
2. **구절 텍스트만 클립보드 복사** — PPT 생성 없이 요청 구절 텍스트(책, 장:절, 본문 형식)만 복사. (BibleSlide v1.3.1 신규 기능, 실제 수요 확인)
3. **릴리스용 빌드 + 배포** — `Release` build, Setup/Portable 패키지, GitHub Releases에 업로드.

**P2 — 검색·출력 강화**
4. **성경 전체 본문 키워드 검색** — 캐시 `bible-v3.db`에 FTS5 추가 → "본문 키워드 → 관련 구절" 검색 (현재는 책→장→절 트리 탐색만 지원).
5. **구절 검색 결과의 "장 단위 PPT" 원클릭** — 검색 결과에서 선택한 구절만 PPT로 생성.
6. **단일 파일 출력 + PDF/이미지** — 장별 `.pptx`를 단일 파일로 병합 옵션, PDF/슬라이드 이미지 출력 (Office interop의 `SaveAs` 지원).
7. **구절 텍스트 정렬/폰트 커스터마이징** — 템플릿 편집 없이 본문 정렬(좌/중/오), 폰트, 크기 설정. (BibleSlide/scripture2slides)

**P3 — UX·생산성**
8. **배경 이미지** — 슬라이드별 이미지 추가/검색 (scripture2slides/BibleSlides).
9. **설교 노트 Import** — 텍스트/Word 원고 입력 → 포인트·구절 슬라이드 자동 구성 (Sermon Slide Pro, Pulpit Slides, easysermon).
10. **슬라이드 크기 선택** (16:9, 9:16, 4:5) — 모바일/스토리용 (scripture2slides).
11. **PPT 제작 기록 개선** — 생성 내역 검색/필터, 이력 삭제, 이력에서 바로 PPT 재생성.
12. **DB 편집기 개선** — 구절/책/장 이름 검색(현재는 prefix만), 여러 구절 선택, 편집 이력/리버티.

**P4 — 확장 (장기)**
13. **웹/클라우드 버전** — 설치 없이 사용 (bibletoppt.com 방식).
14. **macOS 지원** (BibleSlide는 macOS 네이티브 지원).
15. **ProPresenter Export**, **QR 코드 시청 동시 표시**, **3D 성경 지도**, **음성 컨트롤** (BibleSlides, easysermon).
16. **AI 설교 슬라이드 생성** (Pastorly, Pulpit Slides — 주의: 원고 원문 유지).

## 2. 미비 및 개선점 (역할별)

### 2.1 성경 검색 (godpia 중심)
- **단점**: `reading_body.asp`가 장 전체를 반환 → **구절 번호 단위 API가 없음**. range 구절(`dataSec="18-19"`)은 `VersePattern`+`ParseVerseNumber`로 보강했으나,
  원본 사이트 HTML 구조 변경 시 정규식(`BookPattern`, `ChapterPattern`, `VersePattern`)이 깨질 위험.
- **개선**:
  - godpia HTML 파싱을 **단위 테스트**로 고정 (현재는 인덱스 테스트만 존재, godpia 파서 테스트 부재).
  - godpia 응답이 비어질 경우 **fallback 소스** (godpeoplebible/goodtv) 자동 전환 및 사용자에게 안내.
  - **본문 키워드 검색**: SQLite FTS5를 캐시 DB에 적용.
  - godpia 엔드포인트 **rate limit/ 타임아웃/ 재시도** 전략 강화 (현재 30초 타임아웃만 설정).

### 2.2 DB (SQLite, `bible-v3.db`)
- **단점**:
  - `DbEditForm.cs`(기존 DB 편집 화면)와 새 `MainForm.Db.cs` DB 편집기의 **공존 관계** 정리 필요 (코드 중복/비효).
  - **단일 활성 DB** 모델: 여러 DB를 동시에 관리 불가.
  - **자동 백업 미지원**: DB 손실 시 리버티 불가 (리비전만 있고 자동 백업 없음).
  - **DB 경로를 실행 파일 옆**에 둴서 이동 시 불일치 가능 (`BibleContext` 연결 문자열에 경로 하드코딩).
- **개선**:
  - `DbEditForm.cs` 비효화/삭제 후 `DbFileService`를 신규 DB 편집기로 통일.
  - **자동 백업**: DB 변경 시 이전 리비전을 로컬 `backups/`에 자동 저장 (N개 유지).
  - **DB 경로 사용자 지정** (설정 페이지에서 경로 선택, `app.config`에 저장).
  - **DB 내 키워드 검색** (FTS5).
  - **선택 구절/장만 DB 복사** (DB 이관/공유 용도).

### 2.3 PPT 생성
- **단점**:
  - **PowerPoint interop 필수**: Office 설치 없으면 실행 불가.
  - **장별 파일 출력이 기본**: 단일 파일 출력이 없음.
  - **진행도**: 슬라이드 생성 중 취소 지원은 있으나, **진행도(%)/예상 소요 시간** 표시가 부족.
  - **생성 결과 검증**: PPT가 정상 생성되었는지 사용자 확인 없음.
- **개선**:
  - **단일 파일 병합** 옵션 (장별 `.pptx`를 1개 `.pptx`로 병합).
  - **PDF/이미지 출력** 옵션 (`SaveAs` + `PptSaveType`).
  - **진행도 %/예상 시간** 표시.
  - **생성 결과 요약 알림** (파일 수, 크기, 총 슬라이드 수).
  - **대안 엔진**: LibreOffice headless 또는 `python-pptx`를 통해 Office 없이도 생성 가능 (고려 단계).

### 2.4 테마 / UI
- **단점**:
  - 테마는 **WinForms UI만** 적용. PowerPoint 슬라이드 테마는 템플릿에 따라 다름.
  - **토픬** (tooltip) 미지원 → 버튼 목적 불명 (특히 DB 편집기).
  - **글자 잘림**: 오프라인 저장 버튼 높이를 38으로 보강했으나, 다른 버튼/라벨에서 유사한 문제가 있을 수 있음.
  - **대기/로딩 인디케이터** 미지원 (DB 로드, PPT 생성 중).
- **개선**:
  - 모든 버튼에 **토픬** 추가.
  - **로딩 인디케이터** (ProgressBar/BusyIndicator) 추가.
  - **글자 잘림** 전역 점검 (라벨/버튼 높이/자동확장).
  - **스택트/단축키** 지원 (Ctrl+S 저장, Ctrl+N 새로 열기 등).

### 2.5 코드 품질 / 아키텍처
- **단점**:
  - `MainForm`이 **부분 클래스 5개** (Build, History, Templates, Settings, Db)로 분할 — UI 로직과 폼 결합이 깊고, 테스트가 어렵.
  - **테스트 커버리지 부족**: 인덱스 21 + 통합 1 = 22개만 존재. godpia 파서, DB 편집기, PPT 생성 로직 미테스트.
  - **`Microsoft.Office.Interop.PowerPoint` NuGet + `References/Office.dll` 동시**: 리포지토리 내 중복 참조 위험.
  - **`app.config`의 `BibleContext` 연결 문자열**: DB 경로가 코드에 하드코딩된 경향.
  - **로그 출력 부재**: 오류 시 디버깅 어려움 (현재는 MessageBox만 출력).
- **개선**:
  - **서비스/뷰 분리**: `MainForm` 부분 클래스를 `ViewModel`(MVVM 경향) 또는 별도 서비스로 추출.
  - **통합 테스트**: DB 편집기, godpia 파서, PPT 생성(모크)을 테스트.
  - **구조화된 로그**: `NLog`/`Microsoft.Extensions.Logging` 도입, 로그 파일 저장.
  - **Office.dll 참조 정리**: NuGet interop만 사용, 로컬 참조 삭제 (또는 반대로).
  - **`BibleContext` 연결 문자열 외부화**: 설정 페이지에서 DB 경로 입력 가능.

### 2.6 배포 / 운영
- **단점**:
  - **릴리스 빌드 미진행** (Debug만).
  - **Setup 설치 파일 부재** (Portable만).
  - **자동 업데이트 부재**.
  - **리리시 노트** 부재 (현재 GitHub API로 v2.1.0 태그/릴리스 생성 중).
- **개선**:
  - **`Release` build** + `dotnet publish` → 단일 폴더 배포.
  - **Inno Setup** 또는 **WiX**으로 Setup 설치 파일.
  - **자동 업데이트**: `ContactUrl` + GitHub Releases API로 최신 버전 확인/다운로드.
  - **릴리스 노트**: GitHub Releases에 변경 사항 자동/수동 기록.
