## 2. 빌드·실행·배포 방법

### 2.1 개발 빌드
```bash
dotnet build Bible2PPT.sln -c Debug
dotnet test
```
- 산출물은 루트 `build/<프로젝트명>/`으로 일괄 분리 (`Directory.Build.props`).
- 소스 폴더에는 `bin/`/`obj/` 없이 `.csproj`/`.cs`만 유지.

### 2.2 릴리스 실행 파일
```bash
dotnet build Bible2PPT.sln -c Release
```
- **위치**: `build/Bible2PPT/Release/net8.0-windows/Bible2PPT.exe`
- 포함: `Bible2PPT.exe/.dll/.cfg`, `Office.dll`, `Microsoft.Office.Interop.PowerPoint.dll`,
  `Microsoft.Data.Sqlite.dll`, `Microsoft.EntityFrameworkCore.dll` 등.
- **실행 요구**: Windows 10/11, **.NET 8.0 runtime**, **Microsoft PowerPoint 2007+**,
  네트워크(갓피아 소스 사용 시), SQLite.
- 실행 파일 옆에 생성 데이터(`bible-v3.db` 등)가 저장됩니다.

### 2.3 테스트
```bash
dotnet test
```
- **결과: 58/58 통과** (인덱스 21 + 성경서비스 36 + 통합 1).

## 3. 기능 정상 동작 검증 (2.1.1)

| 기능 | 상태 | 검증 방법 |
| --- | --- | --- |
| 성경 검색 (갓피아 중심) | ✅ | 실제 사이트 8 번역·66 책·구절 파싱 + 합치 장 11개 range 확인 |
| PPT 생성 (장별/구절) | ✅ (코드+단위) | 빌드 오류 0, Builder 구절 필터 테스트 |
| 오프라인 저장 (DB 캐시) | ✅ (코드) | 캐시 로직 + 재추하(합치 장) 단위 검증 |
| DB 편집기 | ✅ (코드) | 트리 탐색/구절 편집/저장(다른이름)/복원/리비전 |
| 다크/라이트 테마 | ✅ (코드) | `DarkTheme`/`LightTheme` 적용 |
| PPT 제작 기록 | ✅ (코드) | `MainForm.History.cs` |
| 설정 (파일·DB 정보 표시) | ✅ (코드) | `MainForm.Settings.cs` |
| 합쳐진 구절 (신6:18-19 등) | ✅ | `MergedVerses` + 25개 테스트 |

> **주의**: GUI/PowerPoint 실제 슬라이드 표시는 이 환경(클라운트/호스트)에서
> **직접 실행 검증이 불가**합니다. 빌드·종속·엔드포인트·단위/통합 테스트는 모두 검증됨.
> 실제 PPT 화면은 PowerPoint가 있는 환경에서 확인해 주십시오.

## 4. 남은 기능 / 필요 기능 (상세: `docs/개선_안.md`)

### 4.1 우선순위별 남은 항목

| 우선순위 | 기능 | 상태 |
| --- | --- | --- |
| **P1** | **인앱 자동 업데이트** — `AppConfig.ContactUrl`(GitHub)으로 최신 버전 확인/다운로드 | 미구현 |
| **P1** | **릴리스용 Setup 설치 파일** — Portable 외에 MSI/Setup (PowerShell 또는 Inno Setup) | 미구현 |
| **P2** | **성경 전체 본문 키워드 검색** — 캐시 DB에 FTS5 적용 ("본문 키워드 → 구절") | 미구현 (현재 책→장→절 탐색) |
| **P2** | `DbEditForm.cs`(기존 DB 편집) 정리 — 새 `MainForm.Db.cs` DB 편집기와의 공존·대체 | 미구현 |
| **P2** | 단일 파일 출력 + 다형 출력 — 장별 `.pptx` 병합, PDF/이미지 출력 | 미구현 |
| **P2** | 구절 텍스트 클립보드 복사 | 미구현 |
| **P3** | **UI 개선** — 본문 정렬/폰트/크기/색상, 슬라이드 크기(16:9/9:16/4:5), 배경 이미지 | 미구현 |
| **P3** | **테스트 커버리지 강화** — DB 편집기 통합 테스트, godpia 파싱 추가 | 부분적 |
| **P4** | 확장 — macOS, 3D 성경 지도, QR 코드 동시 표시 | 미구현 |

### 4.2 유사 프로젝트 비교에서 권장 (상세: `docs/개선_안.md`)

- **인앱 자동 업데이트** — `BibleSlide` 지원.

- **슬라이드 크기 커스터마이징** — `scripture2slides.com` 지원.
